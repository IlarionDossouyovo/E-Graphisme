## ⚙️ Configuration du Système

### Services
- **Frontend** : HTML, CSS, JavaScript
- **Backend** : PHP, Node.js, Python
- **IA** : Ollama (DeepSeek, Llama, Mistral, Gemma)
- **Automation** : n8n
- **Base de données** : JSON, PostgreSQL
- **Docker** : Conteneurisation complète

### Démarrage Rapide
```bash
# Docker
docker-compose up -d

# Serveur local
php -S localhost:8000 router.php

# ou Python
python server.py
```
